# SVG Repo fitness category icons

Sources and icon identifiers are listed in catalogue.json. For each item, the
source is https://www.svgrepo.com/svg/{numeric key}/{slug}.
The source pages identify these assets as CC0, uploaded by SVG Repo.
Collection reference: https://www.svgrepo.com/vectors/fitness/outlined/
CC0: https://creativecommons.org/publicdomain/zero/1.0/

The same SVG files are shipped in the mobile app and Web_admin/public/category-icons.
XML declarations and external DOCTYPE declarations are removed for portable
rendering. The boxing icon's colored backing is removed to retain its outline;
the yoga mat's paths use outlines rather than colored fills. All icons inherit
the application's category color at render time.
